# Tool Agent Lab

모델의 도구 호출 과정을 프레임워크 없이 직접 구현하며 배우는 프로젝트입니다.

## 동작 흐름

1. 사용자의 질문과 도구 설명을 모델 API에 보냅니다.
2. 모델이 필요하다고 판단한 도구의 이름과 인자를 `function_call`로 반환합니다.
3. Python 코드가 요청을 확인하고 해당 함수를 실행합니다.
4. 실행 결과나 오류를 `call_id`와 함께 `function_call_output`으로 모델에 전달합니다.
5. 모델은 앞선 맥락과 도구 결과를 바탕으로 답변하거나 다른 도구를 요청합니다.

## 도구

| 도구 | 하는 일 |
| --- | --- |
| `get_current_time` | 한국 현재 시간 확인 |
| `days_until` | 목표 날짜까지 남은 일수 계산 |
| `save_note` | 승인 후 학습 기록 저장 |

## 직접 확인한 것

- 한 응답에 여러 도구 호출이 올 수 있습니다.
- 잘못된 JSON이나 날짜가 들어와도 프로그램을 종료하지 않고, 오류를 도구 결과로 모델에 전달합니다.
- `save_note`는 파일에 쓰기 전에 `[y/N]`으로 사용자 승인을 받습니다. 거절하면 파일을 변경하지 않습니다.
